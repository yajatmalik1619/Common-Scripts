# Common-Scripts
A collection of basic yet frequently used Python scripts for quick data manipulation, preprocessing, and analysis.
These scripts are designed to be simple, reusable, and easy to understand — perfect for learners and for reference use in small projects.

Each script in this repository includes:
  
  -Core functionality implemented in plain Python (with optional NumPy / Pandas usage).

  
  -A sample dataset and example code (commented out by default)(wherever is required).

  
  -Clear structure for direct use or customization.
To see how a script works, simply uncomment the sample code section and run the file.

SCRIPT                                  DESCRIPTION
categorical_encoding_tech.py            Demonstrates ordinal and one-hot encoding without scikit-learn.
imputation_tech.py                      Handles missing values by removing and imputation without the use of scikit-learn.
